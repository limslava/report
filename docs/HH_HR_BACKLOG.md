Дата: 30.07.2026
Источники требований: `HH_HR_MODULE_TZ.md` (интеграция hh.ru), HR-ТЗ «SimpleHR» (заказчик Прямушко Е.Н.), `FARPOST_API_RESEARCH.md` (решение по FarPost).

## Решения заказчика от 30.07.2026

| Вопрос | Решение |
|---|---|
| WhatsApp | **отложено до уточнения у HR**, идея не снята. ## UI/UX, слой 2 — сделано 30.07

- **Живые бейджи в меню** — `GET /hh/badges` (лёгкие count-запросы), опрос раз в минуту + при возврате фокуса (`store/hh-badges-store.ts`). Рекрутер: новые заявки + ждущие решения + интервью сегодня; заявитель: сколько кандидатов ждут его решения. Красная пилюля на «Заявки на подбор», синяя на «Интервью», суммарная на свёрнутом корне меню.
- **SLA «уже N дней»** — в заявке считается `pendingSince` (самая ранняя отправка без решения); на карточке заявителя подпись «N кандидатов ждут вашего решения · уже N дн.», с 3 дней — красным.
- **Матрица «вакансия × этап» на дашборде** (по референсу ATS) — строки: активные вакансии, колонки: Новые/Скрининг/У заказчика/Оффер/Принят, в ячейках цветные счётчики; клик ведёт в список кандидатов с фильтром (`?vacancyId=&stage=`).
- **Сводка вакансий «пончиком»** — CSS conic-gradient, без библиотек графиков.
- **Воронка горизонтальными барами** вместо списка чисел.
- **Карточка кандидата**: навыки чипсами, чип «Отказ: причина» из справочника; фильтр по вакансии в списке кандидатов.
- Смоук в песочнице: 8/8 (логины, роли бейджей, pipeline/vacancySummary, pendingSince, 401 без токена).

## UI/UX, слой 3 — сделано 30.07

- **Канбан-доска кандидатов** — переключатель «Таблица | Доска» (выбор запоминается), колонки-этапы, перетаскивание карточек без сторонних библиотек (HTML5 drag & drop). Бросок на «Отказ» открывает диалог с обязательной причиной — правило справочника не обходится мышкой.
- **Сравнение кандидатов для заказчика** — кнопка «Сравнить кандидатов» в заявке (от 2 ждущих решения): до 4 профилей колонками, характеристики построчно (возраст, город, ЗП, опыт, навыки, образование, комментарий рекрутера), решение в один клик из таблицы. Контакты по-прежнему не показываются.
- **Таймлайн в карточке кандидата** — история событий вертикальной лентой с цветными точками по типу (импорт, этап, статус, комментарий, интервью, письмо), автором и переходом «этап → этап».
- **Мобильный сценарий заказчика** — карточки заявок в одну колонку, кнопки решения от 44px, диалоги на всю ширину, доска с горизонтальной прокруткой.
