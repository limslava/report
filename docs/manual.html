1. Что появилось нового

  • Справочники — единое место, где хранятся водители (с данными для карточек), техника, прицепы и нормы расхода по моделям.
  • Учёт топлива — помесячный учёт по каждой машине: вводятся три числа, всё остальное считается автоматически и сверяется с нормой.
  • В графике контейнеровозов появилась колонка «Прицеп», а карточку водителя со сцепкой теперь можно скопировать в один клик.
  • Направление погрузки в автовозах теперь можно исправить, не удаляя «П».
  • Система предупреждает о несохранённых изменениях при уходе со страницы.

Разделы «Топливо» и «Справочники» находятся в главном меню слева. Каждый пользователь видит только те разделы, которые доступны его роли, и данные только своего региона.

2. Справочники

Раздел ведут руководители и менеджеры КТК своего региона и отдел кадров. Четыре вкладки: Водители, Техника, Прицепы, Модели и нормы.

Водители (33) Техника (30) Прицепы (12) Модели и нормы (5) Добавить

Панель справочников: вкладки и кнопка добавления записи в текущую вкладку.

Общие правила работы

  • Открыть карточку — двойной клик по строке таблицы.
  • Добавить запись — зелёная кнопка «Добавить» справа.
  • Удаление — внутри открытой карточки (кнопка «Удалить»); доступно не всем.

Водители

Карточка водителя: ФИО, телефон, статус (работает/уволен), дата и место рождения, паспорт (серия и номер, дата выдачи, кем выдан), адрес регистрации, ВУ (номер и дата выдачи). Заполнять всё сразу не обязательно — карточку можно дополнять по мере надобности.

Техника

  • Поля: госномер, тип ТС (например, «Грузовой тягач седельный»), модель, цвет, VIN, статус.
  • Модель вводится текстом с подсказками: начните печатать — система предложит существующие модели. Если ввести новую, она автоматически появится во вкладке «Модели и нормы» (один раз — без дублей, регистр не важен).
  • Статусы: в работе, ремонт (машина остаётся в топливе с пометкой), архив (машина перестаёт предлагаться в топливе; история прошлых месяцев сохраняется).

Прицепы

Простой список: номер прицепа (например, АМ9211/25), примечание, статус. Используется для подсказок в графике контейнеровозов.

Модели и нормы

Для каждой модели указываются нормы расхода топлива: зимняя и летняя (л/100 км). Здесь же настраиваются границы зимнего периода (по умолчанию с 1 ноября по конец марта). Норма задаётся один раз на модель и действует для всех машин этой модели.

3. График контейнеровозов

Колонка «Прицеп»

Между «Г/Н ТС» и «Примечанием» появилась колонка «Прицеп». У сцепки с двумя водителями прицеп общий — одна ячейка на строку. Заполняется в диалогах «Добавить» и «Редактировать строку» (двойной клик по ФИО или госномеру).

Подсказки из справочника

В диалогах добавления и редактирования строки поля ФИО, Г/Н ТС и Прицеп подсказывают значения из справочников: начните печатать — появится список. Свободный ввод при этом сохраняется.

В компании может быть включена дата, после которой новые ФИО и госномера в графиках контейнеровозов и автовозов принимаются только из справочника. В этом случае при сохранении система подскажет, что нужно сначала завести карточку в «Справочниках». Уже сохранённые строки и перенос месяца это не затрагивает.

Скопировать данные водителя

Правый клик по строке графика → пункт «Скопировать данные» (сразу под «Копировать»). В буфер обмена попадает готовый текст: ФИО, паспорт, ВУ, машина из этой строки графика (тип, госномер, марка, цвет, VIN из справочника техники) и прицеп из колонки. Вставляйте его куда угодно: заявка на пропуск, письмо, мессенджер.

4. Направления погрузки в автовозах

Как и раньше: при проставлении «П» открывается окно «Направление погрузки». Новое — ошибку теперь можно исправить:

  1. Сделайте двойной клик по ячейке с «П» (у ячейки с заполненным направлением — синяя точка в углу).
  2. Откроется то же окно с уже внесённым направлением.
  3. Исправьте значение и нажмите «Сохранить» — или «Очистить», чтобы убрать направление, не трогая саму «П».

Состав месяца

Какие машины видны в месяце — решаете вы:

  • Добавить — выбор машин из справочника техники (можно несколько сразу; начните печатать госномер).
  • Из прошлого месяца — копирует состав машин прошлого месяца (цифры не копируются — они и не нужны, см. ниже).
  • Убрать машину — правый клик по строке → «Убрать из месяца» (данные этой машины за текущий месяц удалятся, прошлые месяцы не пострадают).

Ввод данных: три числа на машину в месяц

  1. Показания одометра, км — на конец месяца.
  2. Конечный уровень Топлива — остаток в баках на конец месяца.
  3. Заправлено по ППР — одной цифрой за месяц.

Остальное система считает сама:

  • Пробег = одометр этого месяца − одометр прошлого;
  • Начальный уровень = конечный уровень прошлого месяца;
  • Расход, л = начальный + заправлено − конечный;
  • л/100 км и колонка «К норме» — сравнение с нормой модели по сезону: зелёное — в норме или экономия, жёлтое — перерасход до 10 %, красное — больше 10 %.
Первый месяц машины (прошлого месяца ещё нет): «Пробег» и «Начальный уровень» вводятся вручную прямо в ячейки — при наведении на них есть подсказка. Со следующего месяца всё будет подставляться автоматически. Исправленная вручную ячейка подсвечивается бежевым.

Числа можно вводить как удобно («330000», «330 000», с запятой или точкой) — при уходе из ячейки значение само приводится к виду с разделителями разрядов. Не забывайте нажимать «Сохранить».

6. Выгрузки Excel по топливу

Кнопка «Скачать Excel» предлагает два варианта:

  • За месяц — таблица как на экране, с теми же колонками.
  • За год — привычный формат «как в старом файле»: на каждую машину блок из семи показателей, колонки — 12 месяцев, столбец «Итого за год», справа — справочная таблица норм зима/лето по моделям.

7. Несохранённые изменения

Если вы что-то изменили (в топливе, справочниках или графиках) и пытаетесь перейти в другой раздел, сменить месяц или закрыть вкладку браузера — система спросит, что делать:

Несохраненные изменения Вы изменили данные и еще не сохранили их. Сохранить перед переходом? ОТМЕНА   НЕ СОХРАНЯТЬ   СОХРАНИТЬ

«Сохранить» — сохранит и перейдёт; «Не сохранять» — перейдёт, отбросив изменения; «Отмена» — останетесь на странице.
